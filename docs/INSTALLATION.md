# 🚀 Installation Guide

## Quick Start Options

### Option 1: Use Online (Recommended)
The easiest way to use Digital Footprint Eraser is through the hosted version:

**🔗 [Live Demo](https://YOUR_USERNAME.github.io/digital-footprint-eraser)**

- No installation required
- Always up-to-date
- Works on any device with a modern browser
- 100% client-side processing (your data never leaves your device)

### Option 2: Run Locally

#### Prerequisites
- Modern web browser (Chrome 88+, Firefox 85+, Safari 14+, Edge 88+)
- No server requirements (runs entirely in browser)
- Optional: Python 3.x or Node.js for local development server

#### Download & Setup

**Method A: Download ZIP**
1. Go to the [GitHub repository](https://github.com/bharathk2498/digital-footprint-eraser)
2. Click "Code" → "Download ZIP"
3. Extract the ZIP file to your desired location
4. Open `index.html` in your web browser

**Method B: Git Clone**
```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/digital-footprint-eraser.git

# Navigate to the directory
cd digital-footprint-eraser

# Open in browser (double-click index.html)
# OR serve with Python
python3 -m http.server 8000

# OR serve with Node.js
npx serve .

# Then visit http://localhost:8000
