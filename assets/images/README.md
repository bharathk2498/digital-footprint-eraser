# Image Assets Directory

This directory contains all visual assets for the Digital Footprint Eraser application.

## PWA Icons Required

To complete the PWA setup, generate the following icons from the base logo:

### Required Icon Sizes:
- `icon-72x72.png` (72×72px)
- `icon-96x96.png` (96×96px)  
- `icon-128x128.png` (128×128px)
- `icon-144x144.png` (144×144px)
- `icon-152x152.png` (152×152px)
- `icon-192x192.png` (192×192px)
- `icon-384x384.png` (384×384px)

### Shortcut Icons:

### Screenshots:

### Favicon:
- `favicon.ico` (32×32px, 16×16px multi-size ICO file)

## Design Guidelines

### Brand Colors:
- **Primary**: #6366f1 (Indigo)
- **Secondary**: #10b981 (Emerald)
- **Background**: #0f172a (Dark Slate)
- **Accent**: #8b5cf6 (Purple)

### Icon Design:
- Use the eraser icon (🧹) as the primary symbol
- Include shield (🛡️) or lock (🔒) elements for security
- Maintain consistent visual style across all sizes
- Ensure readability at smallest sizes (16×16px)

### Maskable Icons:
- Add 20% padding around the core icon for safe area
- Ensure icon remains legible when cropped to circle/rounded square

## Logo Concept

The Digital Footprint Eraser logo should represent:
- **Privacy Protection** (shield, lock)
- **Digital Cleanup** (eraser, broom)
- **Technology** (modern, clean design)
- **Trustworthiness** (professional appearance)

## Generation Tools

Recommended tools for creating these assets:
- **Figma** (free, web-based)
- **Canva** (templates available)
- **PWA Asset Generator** (automated generation)
- **Adobe Illustrator** (professional)

## Asset Optimization

All images should be:
- Optimized for web (compressed)
- Progressive loading where applicable
- Accessible (high contrast for visibility)
- Retina-ready (2x resolution available)
